## Konsolidierte Master-Workflows

### Workflow 1: KI-gesteuerte Marketing-Pipeline mit Memory-Loop
1. Kontext erfassen (Website, Voice Memo) → in Obsidian speichern
2. TAM aufbauen (Zielunternehmen anreichern, lokal in CSV)
3. Content erstellen (Notebook LM + Hermes) basierend auf Kontext
4. Kampagnen vorschlagen (KI analysiert TAM)
5. Menschliche Prüfung und Genehmigung
6. Automatischer Versand (SmartLead/Instantly)
7. Monitoring & Lernen (Reply-Raten tracken, erfolgreiche Muster in Obsidian)
8. Wöchentlicher Zyklus mit Codex

**Quellen:** 4BxJB7E18f4, qw0xdTtzK1w | **Vollständigkeit:** 0.85

### Workflow 2: KI-Dashboard mit Subgrid-Layout
1. Hermes Dashboard erstellen lassen
2. Dashboard-HTML mit CSS Grid strukturieren
3. Subgrid für konsistente Ausrichtung einsetzen
4. Fallback für ältere Browser bereitstellen
5. Dashboard in Obsidian einbetten oder hosten
