### Step 3: `pdf-generator.tsx` — New Customer-Centric Report Format
- **Remove entirely**: `BillingLineItem`, `BillingSummary`, `InvoiceDocument`, `printInvoice()`, `printServiceRecord()`, `ServiceRecordDocument`
- **Refactor `ReportDocument`**: Replace with task-detail format matching specification:
  ```
  HEADER:  Customer Name | Report Period (date range) | Creation Date
  SECTION per PROJECT:
    Project Key - Project Name
    TABLE: [Datum] | [Aufgabe] | [Notiz (Einzeiler)] | [Dauer (h)]
    FOOTER: Summe <ProjectKey> — <project total>h
  GRAND TOTAL: Gesamtsumme — <grand total>h
  ```
- Accept new data shape from page.tsx: grouped entries per project with individual tasks
- Add German labels throughout (Datum, Aufgabe, Notiz, Dauer, Summe, Gesamtsumme)
- Keep logo support, keep `@react-pdf/renderer` tech
