## Step 2: TimerBar Refactoring (`TimerBar.tsx`)

### Current State
- Already a fixed bottom bar (`fixed bottom-0 left-0 right-0 z-50`)
- Desktop (`hidden sm:flex`): Full row with task selector, description, billable toggle, custom start, elapsed time, pause/stop buttons
- Mobile (`sm:hidden`): Mini-bar with running task title, elapsed time, stop button
- When NO timer running on mobile: Shows task selector + play button inline
- No drag-and-drop, no floating pill — already cleaned up in prior session

### Required Changes (Mobile Bottom Sheet)

**Goal:** On mobile, tapping the mini-bar opens a bottom sheet (50-60% viewport) for task selection, billing toggle, notes, and custom start time. This prevents mobile UI clutter in the mini-bar itself.

#### TimerBar.tsx Changes

##### a) Add Bottom Sheet state:
```
const [bottomSheetOpen, setBottomSheetOpen] = useState(false)
```

##### b) Mobile layout when timer IS running:
- Keep mini-bar compact (pulse dot + task title + elapsed time + stop button)
- Tap the mini-bar → opens Bottom Sheet with:
  - Task title header
  - Pause/Resume button
  - Billing toggle
  - Description input with mentions
  - Custom start time panel

##### c) Mobile layout when NO timer running:
- Mini-bar shows a compact task selector button + play button
- Tap the task selector button OR the mini-bar → opens Bottom Sheet with:
  - Full task search + selection list
  - Billing toggle
  - Description input with mentions
  - Custom start time panel
  - Start button at bottom

##### d) Desktop layout remains UNCHANGED:
- Full-width row with inline controls
- All current desktop behavior preserved

##### e) Use existing `sheet.tsx` (`@base-ui/react/dialog` based):
- Import `Sheet`, `SheetContent`, `SheetHeader`, `SheetTitle`, `SheetTrigger` from `@/components/ui/sheet`
- Use `side="bottom"` for the bottom sheet
- Sheet opens as a drawer from the bottom, ~60% height with rounded top corners

##### f) Remove from mobile inline area:
- Mobile inline task selector (moved into sheet)
- The current `sm:hidden` section gets simplified

### Files to Create/Modify
- **Modify** `TimerBar.tsx`: Add sheet import, state, refactor mobile section, extract sheet content
- No new files needed — sheet content lives inside `TimerBar.tsx` (or extract to a `TimerBottomSheet` sub-component defined locally in the same file)

### i18n
- Existing `timerbar` keys are sufficient; no new keys needed
- Sheet title: reuse `timerbar.collapsed_label` → "Timer"
