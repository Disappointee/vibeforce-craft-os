# Phase 2: Execution Workflow (Timer & Dashboard) - Refactoring Plan

## Overview
Refactor the timer UI from a floating, draggable panel into a static bottom bar (Spotify-model), declutter the dashboard by removing two high-cognitive-load widgets, and clean up orphaned store state.

## Files Involved
| File | Path |
|------|------|
| Timer Store | `frontend/src/lib/store.ts` |
| TimerBar Component | `frontend/src/components/layout/TimerBar.tsx` |
| Dashboard Page | `frontend/src/app/(dashboard)/page.tsx` |

## Step 2: Redesign TimerBar (`frontend/src/components/layout/TimerBar.tsx`)

### Remove
- All drag-and-drop logic: `dragPos` state, `handleDragStart`, `handleDragMove`, `handleDragEnd`, `loadPosition()`, `savePosition()`, `dragStartRef`, `wasDragRef`, `STORAGE_KEY`, `DEFAULT_POSITION`
- `DragHandle` component (lines 674-688)
- `MinimizeButton` component (lines 690-698)
- `isCollapsed` usage (destructured from store)
- `desktopCollapsed` floating pill (lines 800-821)
- `desktopExpanded` draggable expanded bar (lines 824-917)
- `isMobile` hook — no longer needed for mobile overlay logic
- Mobile FAB (`mobileFAB`, lines 705-716)
- Mobile fullscreen overlay (`mobileOverlay`, lines 719-797)
- `showMobileOverlay` state

### New Architecture (Spotify Bottom Bar)
- Single render: `<div className="fixed bottom-0 left-0 right-0 z-50 bg-card border-t border-border shadow-[0_-4px_20px_rgba(0,0,0,0.3)]">`
- **Desktop (`hidden sm:flex`):** Full horizontal row with:
  - Task Select dropdown
  - Description input
  - Billable toggle
  - Custom start time button
  - Elapsed timer ticker (formatTime)
  - Play/Pause/Stop buttons
- **Mobile (`sm:hidden`):** Mini-bar with:
  - Truncated active task title
  - Elapsed time
  - Play/Stop button (large)
  - No complex menus

### Keep (extracted from current code)
- `TaskSelectorDropdown` — reusable for desktop bar
- `BillableToggle` — for desktop bar
- `CustomStartTimePanel` — for desktop bar
- `DescriptionInput` with `MentionDropdown` — for desktop bar
- `formatElapsed` / `formatTime` helper
- `handleStart`, `handleStop`, `handlePauseToggle`, `handleSaveNote`, `handleDescriptionChange`, `handleDescriptionKeyDown`, `selectMention`
- All fetching effects (tasks, users, billable default)
- Elapsed time ticker effect
- `mentionDropdownEl`
- Imports (adjusted for removed unused ones)
